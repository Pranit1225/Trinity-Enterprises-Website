# Trinity Enterprises — Landing Page Rebuild

Development version of the new Trinity Enterprises website.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Motion for React
- Lucide React

The project is intentionally using placeholder company details and visuals. Replace them with the final verified content/assets before production launch.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```
